# Welcome to the Maria Project with the robotic arm SO-101

This project consists of the the study and application of robotics using the robotic arm SO-101 by LeRobot [1]. Our main goal is to implement a simulation environment in MuJoCo and enable it for the training of reinforcement learning policies.

The tasks are defined in the issues sections and the main documentation is presented as follows.

1. [Simulation environment setup](01_simulation_setup.md)
2. Implementation of robotic arm in simulator
3. Testing of teleoperation of robotic arm using mobile phone

[1] [SO-101 LeRobot Arm](https://huggingface.co/docs/lerobot/so101)
